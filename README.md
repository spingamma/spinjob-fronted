# 🚀 Frontend de Tarjetoso

## 🛠️ Herramientas previas
Para poder trabajar en este proyecto, necesitas tener instalado:
- **Node.js (versión LTS)**: Puedes descargarlo desde [nodejs.org](https://nodejs.org/).
- **Git**: Para poder descargar el código y subir tus cambios.

## 📦 Instalación
1. Abre tu terminal y ubícate en la carpeta del proyecto.
2. Descarga todas las dependencias necesarias ejecutando:
   ```bash
   npm install
   ```

## 💻 Ejecución local
1. Para levantar la aplicación en tu computadora, ejecuta:
   ```bash
   npm run dev
   ```
2. Una vez que inicie, abre tu navegador web y visita: 👉 **[http://localhost:5173/](http://localhost:5173/)**

*Para apagar el servidor, simplemente presiona `Ctrl + C` en la terminal.*

## 📤 Pasos para subir cambios
Cuando termines de programar y quieras guardar tus actualizaciones en el repositorio remoto, sigue estos 3 pasos:

1. Agrega todos tus archivos modificados:
   ```bash
   git add .
   ```
2. Guarda los cambios con un mensaje que describa lo que hiciste:
   ```bash
   git commit -m "tu mensaje aquí"
   ```
3. Sube los cambios a la nube (asegúrate de estar en tu rama correspondiente):
   ```bash
   git push origin main
   ```
